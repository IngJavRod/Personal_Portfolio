About Me

Hello! I'm an engineer with full stack experience in frontend and backend development. I'm passionate about building efficient and secure tech solutions, from automated access systems to API integration and modern web architectures.

Software Engineer & Mechatronics Engineer.

My journey into development began with a simple curiosity: understanding how technology works. As a Mechatronics Engineer, I was always interested in the inner workings of systems—from sensors and circuits to the code that automates tasks or communicates with devices.

That curiosity led me to explore software development. What started as small scripts turned into more complex projects where I discovered the true power of building solutions.

Today I build and operate production software end to end: a multi-tenant SaaS platform running on AWS (EC2, Docker, Nginx, PostgreSQL), 50+ custom ERP modules written in Python, and integrations with payment gateways, marketing platforms and messaging services. I own the full cycle — from writing the code to deploying it, migrating the databases, monitoring it in production and training the people who use it.
